# JARVIS Dashboard V3

Persönliches Dashboard für Laptop und Desktop.

## Funktionen
- Responsive Command-Center-Layout
- Lokale Aufgaben und Termine via LocalStorage
- Live-Wetter
- Morgenbriefing
- Smart-Home-Connector-Fallback
- Xiaomi-S1-Datenmodul / CSV-Import
- Aktive Projektmatrix

## Start
`index.html` im Browser öffnen. Für lokale Entwicklung eignet sich z. B. VS Code Live Server.

## Daten
Bestehende Daten des früheren Prototyps bleiben über den LocalStorage-Schlüssel `jarvis_functional_preview_v1` kompatibel.
